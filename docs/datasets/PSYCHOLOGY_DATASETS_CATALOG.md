## 0. 使用说明

### 0.1 核实状态三级口径

| 状态 | 含义 |
|---|---|
| 已打开原始页面 | 本次或补充轮实际打开数据集落地页/仓库页，看到标题、样本量或许可条款 |
| 仅检索到引用 | 在论文、搜索引擎摘要、项目登记或二次文献中确认存在，但未打开原始下载页 |
| 未核实 | 只有名称/线索，链接或关键字段待查；**不得据此对外声明许可与规模** |

### 0.2 标签类型口径

- **连续**：原始总分或条目分可直接回归（PHQ-9 0–27、BDI-II 0–63、CES-D 0–60、HAMD-17 0–52、MADRS 0–60）。
- **分级**：有明确切点（PHQ-9 5/10/15/20；GAD-7 5/10/15；DASS-21 轻/中/重/极重）。
- **二分类**：病例/对照、抑郁/非抑郁、自杀风险有/无。
- **多标签**：症状级、条目级或危机类型多标签。
- **无标签**：只有对话/文本/咨询记录，无量表或诊断标签。

### 0.3 使用红线

1. **已参与训练的集不得再称「外部验证」**：本目录 D07（Depresjon 原始活动记录）、D17（PHQ-9 682 条）、M01（MMPsy 及其派生中文语料）均在项目训练链路内，只能作同分布基线或压力测试。
2. **许可未核实的数据不得进入交付物或对外发布**；CC BY-NC / ND 条款下不得商用、不得改写分发。
3. **非中文集只能验证方法，不能验证中文人群的严重度分级**（见 §7.4）。

### 7.2 口径纠正与硬限制（可直接引用）

1. **「用两个集分别补 panic 与 financial」的拼法不成立**：MIDUS 一个集已同时具备 12 个月 panic（`B1PPANIC`）与主观 financial strain（0–6），不需要拆成两个数据集。真正缺口是 **`academic_pressure` + `PHQ-9` + 学生人群** 的组合。
2. **NHIS 明确排除**：`PANICYR` 仅 1999 年，PHQ-8 仅 2019/2022/2025，年份不相交，无法在同一受试者上同时获得两者。
3. **NSDUH 的 panic 条目未核实**：公开文件是否含 panic 条目尚未查证，**不可当作已确认事实**写入论文。
4. **取值域冲突**：MIDUS financial strain 为 0–6，项目训练域为 0–5；LR 系数不能直接外推，必须先重标度（如分位映射或等距压缩），并在论文中报告重标度方法。
5. **完全共线**：项目内 `stress_level` 与 `academic_pressure` 的相关系数为 1.0；用单一压力源填充时，一个值同时喂两个字段，敏感性分析只能测「压力总因子」，**无法分离学业压力**。
6. **ACHA-NCHA 的 panic 不是发作**：它是「12 个月内被诊断/治疗」清单项，不能当 `panic_attack`（发作）标签。
7. **HMS 的 panic 仅是 2007 波、4 周口径**：不能与 12 个月口径混用，也不能代表近年学生。
8. **WMH-ICS 是唯一跨文化阈值稳定性来源**：但它只对 consortium 开放、且用 CIDI-SC 而非 PHQ-9，不能直接给项目阈值背书。

### 7.3 能力边界（四级判定）

| 能力 | 判定 | 依据 |
|---|---|---|
| 方向验证（panic / financial / academic 是否有信号） | **可行** | MIDUS、WMH-ICS、KYRBS、HMS 等提供字段级关联 |
| 字段敏感性（缺某字段时性能如何变化） | **部分可行** | MIDUS 可做 panic+financial 双字段消融；academic 只能靠 KYRBS 单条目代理 |
| 阈值迁移 / 回归系数校准 | **不可行** | 量表不等值、取值域不同（0–6 vs 0–5）、人群非学生 |
| 跨文化阈值稳定性 | **仅 WMH-ICS 满足** | 18 国/77 校统一 CIDI-SC 协议；其余集国别/量表不可比 |

### 7.4 三条方法论结论（论文可直接引用）

1. **没有任何非中文数据集能验证中文人群的严重度分级，只能验证方法。** 跨语种迁移的合法结论上限是「方法/结构可迁移」，不是「阈值/分级可迁移」。
2. **PHQ-8/9、BDI-II、HAMD-17、MADRS、CES-D 之间没有等值性证据，只能分带映射。** 任何跨量表回归都必须声明映射规则（如仅按 severity band 对齐），不得把总分当同一潜变量。
3. **中文抑郁表达偏躯体化、英文偏情绪词，TF-IDF 词表近乎不重叠。** LLM 机翻生成的「多语种严重度集」会造成虚假可迁移性，**不可作为证据**。
