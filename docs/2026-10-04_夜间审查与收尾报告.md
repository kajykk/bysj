## 12. 环境事实（下次直接复用）

- **网络**：代理只通 GitHub；`pypi.org` / `huggingface.co` / 清华镜像不通。**可用**：腾讯云、阿里云 PyPI 镜像，`hf-mirror.com`
- **大文件**：镜像每次连接只给约 5.7MB 就中断 → 必须 `curl -C -` 断线续传 + 完整性校验（**小文件也会被截断且 curl 返回 0**，`tokenizer.json` 曾因此损坏）
- **`sentence-transformers 6.1.0` 在 transformers 5.5.0 下不可用**（调 `AutoProcessor`，老模型无 processor 配置）→ 手工 `AutoTokenizer` + `AutoModel` + mean pooling
- **vue-tsc 必须用 `tsconfig.app.json`**；跑 `tsconfig.json`（references 容器）永远 0 错误，是假绿
- **WorkBuddy shim 噪声**：pytest 结束后 teardown 抛 `SystemExit: 1` / `SAFE_DELETE_BULK_GUARD_ERROR`，非测试失败
- **warning 去重陷阱**：连续 `joblib.load` 多个文件时，Python 的 warning 去重会让「第一个之后」全假阴性 → 每个文件独立子进程检测
