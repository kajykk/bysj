## 1. 目标分析

### 1.1 当前模型资产盘点

| 模态 | 当前最优模型 | 数据集 | 当前指标 | 主要瓶颈 |
|---|---|---|---|---|
| 结构化 | Logistic Regression / Random Forest（`models/structured/`） | Student Depression Dataset（测试集 5,581 条） | LogReg：Acc 0.8382 / F1 0.8589 / AUC 0.9174；RF：Acc 0.8389 / F1 0.8651 / AUC 0.9147 | **生产模型特征契约破损**（推理缺列 `SleepDurationOrdinal`、`AgeGroup`、`DietaryHabitsOrdinal`、`Working Professional or Student`，触发 `retrain_needed=true`）；线性/浅树模型容量不足，指标触及平台期 |
| 文本 | TF-IDF + Logistic（`models/artifacts/text_depression_classifier/`）；双语模型 `models/text/improved_bilingual_model.pkl` | Reddit Depression（测试集 1,547 条） | Acc 0.9677 / F1 0.9681 / AUC 0.9956 | 指标异常偏高，疑似**单域过拟合/标签泄漏风险**；Reddit 英文语料与中文校园场景域差距大；缺乏域外验证集，真实泛化能力未知 |
| 生理 | PyTorch MLP（`model_assessment/physiological_optimization/pytorch_mlp_optimized.pt`） | 自采生理数据集 + Depresjon | 自采集：val F1 0.7314 / AUC ≈ 0.755–0.769；Depresjon：F1 0.9530 / AUC 0.9940 | 自采集上为**最弱模态**（F1 仅 0.70–0.73）；深层变体 `Deep[64,48,32,24,16]` 已标记 `overfit=true`；两个数据集指标差距悬殊，域敏感性强 |
| 融合 | 静态加权融合（structured 0.55 / text 0.30 / physiological 0.15）+ Keras DNN/GNN/Transformer 候选（`models/keras/`） | 多模态合并集 | 未建立统一融合基准 | 权重为**人工设定**，未在验证集上学习；4 个 Keras 深度融合候选未与加权基线做显著性对比；缺乏概率校准，风险阈值缺乏成本依据 |

### 1.2 核心问题清单

1. **P0 契约破损**：生产结构化模型推理缺列，实际运行在降级/回退路径上，等于"带着镣铐跑"。
2. **泛化未知**：文本模态 0.9956 的 AUC 明显超出该类任务合理区间，存在数据泄漏或单域过拟合嫌疑，必须用域外数据揭穿真实水平。
3. **短板模态**：生理模态 F1 0.73 且过拟合，拖累三模态融合的上限。
4. **融合原始**：静态权重未学习化，深度融合候选未做对照验证。
5. **校准缺失**：各模态输出概率未校准，直接用于风险分级阈值（高危召回无成本敏感优化）。
6. **部署裸奔**：sklearn pickle + 可选 BERT，无量化/蒸馏/ONNX 加速，文本深度模型上线后的延迟无保障。

### 1.3 可量化优化目标

| 目标项 | 基线 | 目标值 | 说明 |
|---|---|---|---|
| 结构化模态 AUC | 0.9174 | **≥ 0.94** | GBDT + 调参 + 特征契约修复 |
| 结构化模态 F1 | 0.8651 | **≥ 0.90** | 同上 |
| 文本模态域外 AUC | 未测量（域内 0.9956） | **≥ 0.90** | 新建域外/中文验证集后测得的真实指标 |
| 中文校园文本 F1 | 未测量 | **≥ 0.85** | 双语模型或 MacBERT 微调后 |
| 生理模态 val F1 | 0.7314 | **≥ 0.80** | 正则化重构 + 数据质量分层 |
| 生理模态 AUC | ≈ 0.755 | **≥ 0.83** | 同上 |
| 融合 AUC 增益 | 静态加权基线 | **较最优单模态 +2pt** | 学习融合（stacking/门控），需显著性检验 |
| 概率校准 ECE | 未测量 | **≤ 0.05** | Platt/Isotonic 校准后 |
| 高危类别召回 | 未按阈值优化 | **≥ 0.95**（precision ≥ 0.75 约束下） | 成本敏感阈值 |
| 单模态推理 P95 | 未测量 | **< 100ms**；端到端维持 < 2s | 管线缓存 + 量化 |
| 文本深度模型体积 | BERT 全量 | **压缩 ≥ 50%，AUC 损失 < 0.5pt** | 蒸馏 + 动态量化 |

## 2. 优化计划总表

> 优先级定义：**高** = 影响生产正确性或安全底线，立即做；**中** = 显著提升指标，本迭代做；**低** = 锦上添花，排期允许再做。

|---|---|---|---|---|---|---|
| D1 | 修复结构化特征契约：将 `SleepDurationOrdinal`/`AgeGroup`/`DietaryHabitsOrdinal` 等派生列并入统一的"训练-推理同源"特征管道（`feature_engineering.py` 单一入口），补契约单测 | 数据 | **高** | 消除生产降级路径，恢复正常推理；推理成功率恢复 ≥99.9% | **中**：重放历史数据可能引入分布偏移，需 PSI 校验 | 契约校验通过率 100%；推理成功率 ≥99.9%；新旧管道输出一致性 ≥99.99% |
| D2 | 数据清洗与标签审计：Reddit 自标签噪声抽检、PHQ-9 标签口径统一、重复/泄漏样本剔除（近重复检测） | 数据 | **高** | 降低标签噪声，泛化指标 +1~3pt；排除文本"虚高"嫌疑 | **低**：剔除量过大可能损失少数类 | 清洗后 5-fold CV AUC 不低于基线；噪声样本剔除率 <10%；文本域内 AUC 回落至合理区间（≤0.98 视为去泄漏成功） |

| M1 | 结构化模型升级：XGBoost/LightGBM 替换 LogReg/RF，贝叶斯超参搜索（复用 `hyperparameter_tuning.py`），单调性约束（如 PHQ-9 分数单调） | 模型 | **高** | AUC 0.9174 → ≥0.94；F1 0.8651 → ≥0.90 | **中**：小数据上过拟合；可解释性下降（需 SHAP 补足） | 5-fold CV AUC ≥0.94；测试集 AUC 与 CV 差 <2pt；SHAP 特征方向与临床先验一致 |

## 3. 分阶段实施路线与验收标准

### 阶段一：止血与度量基准（第 1–2 周）

**任务**：D1、D2、D3、M5、P1
**目标**：先让生产模型"站起来"，并建立可信的度量基准。

| 验收项 | 验收标准 |
|---|---|
| 特征契约修复 | 契约单测全绿；生产推理成功率 ≥99.9%；新旧管道输出一致性 ≥99.99% |
| 数据清洗 | 清洗后 CV AUC ≥ 基线；泄漏样本剔除清单归档 |
| 域外验证集 | ≥2,000 条、κ ≥0.75、合规审查通过，文本模态域外基线指标出报告 |
| 概率校准 | 各模态 ECE ≤0.05，阈值-成本对照表归档 |
| 推理管线 | 单模态 P95 <100ms，端到端 <2s 压测报告 |

### 阶段二：单模态提能（第 3–5 周）

**任务**：M1、M3、T1、T2、D4、D5
**目标**：结构化与生理两个短板的指标拉升。

| 验收项 | 验收标准 |
|---|---|
| 结构化 GBDT | 5-fold CV AUC ≥0.94，F1 ≥0.90；SHAP 解释与临床先验一致 |
| 生理 MLP 重构 | val F1 ≥0.80、AUC ≥0.83、overfit 标志清零 |
| 不平衡对照 | 三路实验报告归档，选型依据明确，recall ≥0.90 时 precision ≥0.75 |
| 数据增强 | 增强后 CV F1 ≥ 基线且 PSI <0.1 |
| 训练规范 | 全部实验 5-fold × 3 seeds，报告含均值±std 与 CI |

### 阶段三：文本升级与融合学习化（第 6–9 周）

**任务**：M2、M4、T3
**目标**：攻克文本域泛化与融合增益。

| 验收项 | 验收标准 |
|---|---|
| 文本预训练模型 | 域外 AUC ≥0.90；中文集 F1 ≥0.85；延迟满足 P2 联动预算 |
| 学习融合 | 嵌套 CV 下融合 AUC 较最优单模态 +2pt，DeLong p<0.05；缺失模态退化不劣于现有 4 层回退 |
| 显著性规范 | 所有对比结论附统计检验 |

### 阶段四：压缩上线与持续治理（第 10–12 周，之后转入常态）

**任务**：P2、P3、P4
**目标**：新模型安全、轻量地上线，并接入既有模型治理闭环。

| 验收项 | 验收标准 |
|---|---|
| 量化/蒸馏 | 体积 -50% 以上、AUC 损失 <0.5pt、学生模型保留 ≥97% 教师 F1 |
| 发布门禁 | 金丝雀 PSI <0.1；回滚演练 <5min；发布与回滚记录完整 |
| 治理闭环 | 漂移检测、自动回滚、模型监控覆盖全部新模型 |

## 5. 配套机制

1. **实验登记**：所有训练实验写入 `models/experiments/` 并在 `models/training_jobs.json` 登记（job_id、配置哈希、指标、数据版本）。
2. **复现规范**：固定 seed=42 起步，5-fold × 3 seeds；数据版本与代码 commit 双向绑定。
3. **上线门禁**：新模型必须依次通过——契约单测 → CV 指标达标（含 CI）→ 校准 ECE 达标 → 压测达标 → 金丝雀观察期 PSI <0.1，任一环节失败自动回滚（复用 `canary_controller.py` / `drift_detector.py`）。
4. **指标看板**：各模态 AUC/F1/ECE/P95 延迟接入 Grafana，与既有 Prometheus 指标体系统一。
5. **回退原则**：任何优化项若导致线上核心指标回退，立即回退至上一稳定版本，并在本计划风险登记册中补记。

- **高优（立即启动）**：D1 特征契约修复、D2 数据清洗、D3 域外验证集、M1 结构化 GBDT、M2 文本预训练升级、M3 生理正则化重构、M5 概率校准、P1 推理管线优化

- **低优（排期允许）**：T3 批量/优化器扫描、P3 知识蒸馏专项
