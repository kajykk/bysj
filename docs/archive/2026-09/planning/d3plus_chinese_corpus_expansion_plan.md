# D3+ 中文目标域语料扩充方案

> **版本**: v1.0  
> **日期**: 2026-07-23  
> **阶段**: v2.0 S1 止血与文本数据攻坚  
> **目标**: 将中文目标域语料从 1,275 条扩充到 ≥ 5,000 条,支撑 M2 BERT 微调达到域外 F1 ≥ 0.65

## 1. 背景与动机

### 1.1 当前危机
- **文本模态域外失效**: 英文 TF-IDF 模型在中文域外 F1=0.0147(完全失效)
- **M2 BERT 微调**: F1=0.59(1275 条 mmpsy 数据),T1 网格搜索最优 F1=0.6029,均未达 0.65 目标
- **根因**: 1,275 条中文数据不足以支撑 BERT 微调到更高性能
- **D2 审计发现**: 生产模型真实 F1=0.7891(英文域内),历史 F1=0.965 为评估脚本自训自评的误导性结果

### 1.2 扩充必要性
| 数据量 | 预期 F1 | 依据 |
|--------|---------|------|
| 1,275 条(当前) | 0.59-0.60 | M2/T1 实测 |
| 2,500 条 | 0.62-0.65 | BERT 微调经验下限 |
| 5,000 条 | 0.65-0.70 | BERT 微调合理预期 |
| 10,000 条 | 0.70-0.75 | 充分微调 |

## 2. 数据源分析

### 2.1 现有种子数据
- **mmpsy_scores.csv**: 1,275 条中文学生访谈转录 + PHQ-9 标签
  - 来源: mmpsy 心理测量项目
  - 格式: 多段对话(用 `|` 分隔),phq9_binary 二分类标签
  - 阳性率: ~30%
  - 文本长度: 平均 332 字符

### 2.2 公开数据集调研结果

| 数据集 | 规模 | 标签类型 | 可用性 | 备注 |
|--------|------|----------|--------|------|
| SMP2020 微博情绪 | 35,000+ | 6 类情绪 | ✅ 公开 | sad ≠ depression,标签映射有损失 |
| MODMA | 1,000+ | PHQ-9 | ❓ 待确认 | 中文多模态抑郁,含文本模态 |
| CTDD | 未知 | 抑郁二分类 | ❓ 待确认 | 微博爬虫构建,可能已下架 |
| MentalChat16K | 16,000 | 对话 | ✅ 公开 | 英文心理咨询,非抑郁诊断 |
| HuggingFace 简搜 | <1,000 | 混合 | ✅ 公开 | 质量参差不齐 |

**结论**: 公开中文抑郁诊断数据集极度稀缺,无法直接获取 5,000 条 PHQ-9 标注语料。

## 3. 扩充策略:混合方案

### 3.1 策略概览

```
种子数据 (1,275 条)
    │
    ├── 策略 A: 回译增强 (×2) → 2,550 条
    │   └── 中文 → 英文 → 中文 (Helsinki-NLP/opus-mt)
    │
    ├── 策略 B: 同义词替换 (×1) → 1,275 条
    │   └── jieba 分词 + 同义词词林替换 (替换率 15%)
    │
    ├── 策略 C: LLM 伪标注生成 → 1,500 条
    │   └── 模拟中文校园抑郁表达 + PHQ-9 评分
    │
    └── 汇总去重 → ~5,000+ 条
```

### 3.2 策略 A: 回译增强

**方法**: 
- 使用 `Helsinki-NLP/opus-mt-zh-en`(中→英)和 `Helsinki-NLP/opus-mt-en-zh`(英→中)翻译模型
- 对 mmpsy 1,275 条文本进行中→英→中回译
- 保留原始 PHQ-9 标签

**预期产出**: 2,550 条(原始 1,275 + 回译 1,275)

**优点**: 
- 保留语义和标签
- 生成文本自然度较高
- 无需 API 成本(本地模型)

**缺点**: 
- 需要下载翻译模型(~600MB)
- 回译文本可能丢失部分语义细节
- 多段对话(用 `|` 分隔)需分段回译

**质量控制**: 
- 计算回译前后文本的 BERTScore,过滤分数 < 0.7 的样本
- 人工抽检 5%(~128 条)确认语义一致性

### 3.3 策略 B: 同义词替换

**方法**: 
- 使用 jieba 分词
- 对非抑郁关键词(如"今天"/"感觉"/"学习")进行同义词替换
- 替换率 15%,保留抑郁核心词汇不变
- 保留原始 PHQ-9 标签

**预期产出**: 1,275 条

**优点**: 
- 实现简单,无需额外模型
- 保留标签和核心语义

**缺点**: 
- 多样性提升有限
- 同义词替换可能改变语气

### 3.4 策略 C: LLM 伪标注生成

**方法**: 
- 设计 prompt 模板,模拟中文校园场景的抑郁表达
- 使用 GPT-4o / Claude / 国内 LLM 生成文本
- 用 PHQ-9 量表对生成文本评分(LLM 自评或规则映射)

**Prompt 模板设计**:
```
你是一位心理学研究员,需要生成中文校园抑郁表达文本用于模型训练。

场景设定:
- 大学生/研究生群体
- 涵盖 PHQ-9 九个维度:兴趣减退、情绪低落、睡眠问题、疲劳感、食欲变化、自我评价低、注意力问题、精神运动迟缓、自杀意念
- 严重程度分级: Minimal(0-4)、Mild(5-9)、Moderate(10-14)、Moderately Severe(15-19)、Severe(20-27)

请生成 {n} 条中文文本,每条文本:
1. 模拟学生的真实表达(第一人称)
2. 长度 50-300 字
3. 对应 PHQ-9 评分 {level}
4. 包含至少一个该级别的典型症状描述

输出格式:
{"text": "文本内容", "phq9_score": 数字, "phq9_level": "级别", "phq9_binary": 0或1}
```

**预期产出**: 1,500 条
- Minimal/Mild: 600 条(阴性,phq9_binary=0)
- Moderate/Severe: 900 条(阳性,phq9_binary=1)

**优点**: 
- 语义多样性高
- 可控制标签分布
- 领域匹配(校园场景)

**缺点**: 
- 需要 LLM API 成本(~$5-10 for 1500 条)
- 生成文本可能模式化
- 标签质量依赖 LLM 自评准确性

**质量控制**: 
- 人工抽检 10%(150 条)
- 用 mmpsy 训练的 BERT 模型对生成文本打分,过滤置信度 < 0.3 的样本
- 多样性检查:计算生成文本间 BERTScore,过滤相似度 > 0.9 的重复

## 5. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 回译文本不自然 | 降低模型泛化 | BERTScore 过滤 + 人工抽检 |
| LLM 生成文本模式化 | 模型过拟合 | 多样性 prompt 设计 + 相似度过滤 |
| 伪标注标签噪声 | 模型学习错误标签 | 人工抽检 10% + 置信度过滤 |
| 数据泄露(增强样本与测试集重叠) | 评估虚高 | 严格 train/test 分离,增强只对训练集进行 |

## 6. 验收标准

- [ ] 标签分布平衡(阳性率 25-40%)
- [ ] 文本多样性:平均 BERTScore < 0.85
- [ ] 人工抽检准确率 ≥ 85%
- [ ] M2 BERT 微调域外 F1 ≥ 0.65
