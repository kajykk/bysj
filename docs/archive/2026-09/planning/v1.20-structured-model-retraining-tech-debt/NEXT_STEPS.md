# NEXT STEPS — v1.20 后续建议

> **日期**: 2026-05-01
> **基于**: v1.20 交付成果

## 立即行动 (v1.21 候选)

### 1. 真实数据重训 (P0)
- **背景**: 当前模型基于合成数据训练，真实世界表现待验证
- **行动**: 收集或标注真实学生心理健康数据，在相同 14 特征集上重训 LogisticRegression
- **验收**: 真实数据上 F1 ≥ 0.85

### 2. 多级风险标签训练 (P1)
- **背景**: 当前模型为二元分类器（风险/无风险），无法细粒度区分风险等级
- **行动**: 使用 ordinal regression 或 multi-class 训练，使模型直接输出 5 级风险
- **验收**: 5 级准确率 ≥ 80%

### 3. 生理模型对齐 (P1)
- **背景**: PhysiologicalMLP 的重训路径与结构化模型类似，但目前仍走旧路径
- **行动**: 参考 `train_structured.py` 模式，创建 `train_physiological.py`

## 中期改进 (v1.22+)

### 4. 英文危机检测支持 (P1)
- CrisisDetector 增加英文关键词和规则，支持双语输入

### 5. 模型性能监控仪表盘 (P2)
- 在生产环境中追踪模型预测分布、fallback 频率、推理延迟
- 当 fallback 率 > 5% 或推理延迟 > 200ms 时触发告警

### 6. CI/CD 模型验证流水线 (P2)
- 每次模型重训后自动运行校准验证
- 比较新旧模型在测试集上的统计显著性（McNemar test）

### 7. 前端性能优化 (P2)
- charts chunk (813 kB) 考虑 ECharts 按需引入（tree-shaking）
- vendor chunk (601 kB) 分析是否可移除未使用的依赖
- vue-core chunk (894 kB) 考虑 CDN 加载 Element Plus
