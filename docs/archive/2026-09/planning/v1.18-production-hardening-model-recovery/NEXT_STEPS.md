# 下一步建议 — v1.18-production-hardening-model-recovery

> **生成时间**: 2026-05-01
> **基于迭代**: v1.18-production-hardening-model-recovery
> **状态**: 规划中

## 1. v1.19 建议方向

### 方向 A: v1.19-model-upgrade（模型升级）

**目标**: 将文本模型从 TF-IDF 升级为 BERT

**任务**:
- 调研中文预训练 BERT 模型（如 macbert-base-chinese）
- 构建心理健康领域微调数据集
- 实现 BERT 文本分类训练和评估
- 替换现有 TF-IDF 模型
- 保留 TF-IDF 作为 fallback

**预期收益**:
- 文本风险识别准确率提升 15-20%
- 更好理解中文情感表达细微差别

**工作量**: 大（约 2-3 周）

---

### 方向 B: v1.19-physiological-enhance（生理模型增强）

**目标**: 扩展生理模型特征

**任务**:
- 增加 HRV（心率变异性）特征
- 增加体温、血氧等可穿戴设备数据支持
- 实现生理数据时序分析
- 优化生理模型与结构化模型融合权重

**预期收益**:
- 生理模型预测准确率提升
- 支持更多可穿戴设备

**工作量**: 中（约 1-2 周）

---

### 方向 C: v1.19-performance-optimization（性能优化）

**目标**: 提升系统性能和可扩展性

**任务**:
- API 响应时间优化（缓存、异步）
- 数据库查询优化（索引、分页）
- 前端加载优化（懒加载、代码分割）
- 压力测试和容量规划

**预期收益**:
- API 平均响应时间 < 200ms
- 支持 1000+ 并发用户

**工作量**: 中（约 1 周）

## 3. 决策建议

**推荐下一步**: **方向 A (v1.19-model-upgrade)**

**理由**:
1. v1.18 已完成生产硬化，系统稳定
2. 模型升级是长期规划中的核心目标
3. BERT 升级可显著提升文本理解能力
4. 与 v1.17 的文本安全增强形成完整闭环

**备选方案**: 如果生理数据是首要关注点，可选择 **方向 B (v1.19-physiological-enhance)**。
