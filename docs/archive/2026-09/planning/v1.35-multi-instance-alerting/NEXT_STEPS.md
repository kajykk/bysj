## 1. v1.36 推荐方向 (P0)

### 1.1 告警可视化与可观测性 (P0)

**目标**: 告警系统全链路可视化

- 告警趋势图 (按 severity / rule, 时间窗口)
- 平均响应时间 (fired → acknowledged)
- 升级率统计 (按 escalation_level)
- 通道成功率 (email / webhook / 企业微信)
- 静默规则命中率
- AM 同步成功率 / 失败率

**预计工作量**: 2-3 天

### 1.2 告警根因分析 (RCA) 助手 (P0)

**目标**: 告警爆发时提供上下文

- 同期其他告警列表
- 关联 DeploymentLog / ModelInference / Drift 事件
- 历史告警频率
- 相关用户风险评分

**预计工作量**: 2 天

### 1.3 锁监控与清理任务 (P1)

**目标**: Redis 锁可观测性

- 锁命中率 (Redis 锁 vs SQL 降级)
- 锁等待时间
- 锁失败原因 (Redis 不可用 vs 锁被占用)
- 定期清理异常锁 (TTL 失效后残留)

**预计工作量**: 1 天

## 3. 长期规划 (P2)

### 3.1 归档冷存储

- 90 天前数据下沉到 S3 / OSS
- 本地仅保留 90 天热数据
- 查询时按需加载冷数据

### 3.2 跨实例告警合并

- 同一 fingerprint 多实例产生, 合并为单条
- 全局告警视图 (不再按实例)
- 解决告警风暴的终极方案

### 3.3 智能告警抑制

- 关联告警自动识别
- 父子告警关系 (parent → children)
- 子告警被父告警抑制

### 3.4 SLO/SLI 管理

- 错误预算 (Error Budget) 跟踪
- 关键路径 SLO 定义
- 燃烧率告警

### 3.5 多租户告警路由

- 机构/学校级别路由
- 不同租户不同通道
- 租户级别静默规则
