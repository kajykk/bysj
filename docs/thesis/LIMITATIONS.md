# 局限性（LIMITATIONS · ROUND_29 · P2-56 更新；ROUND_28 · P2-55 建立）

> **纪律**：本文局限性与论文正文同源——每个数字都带 `docs/thesis/CLAIMS_LEDGER.md`
> （下称「台账」）编号，可由 `backend/scripts/modeling/eval/verify_thesis_numbers.py`
> 从已提交产物复算。负结果不隐藏：以下每一条都在结果章节有对应表述。

## 1. 数据层面的局限

1. **仓内没有「同源且齐备」的外部验证数据。** 生理模态的 depresjon 数据集 1029 行
   [S-01] 是唯一经过完整评估流水线的来源；Kaggle Wearable 数据 10000 行 [S-02]
   仅用于迁移测试，且其评估 json 明确记载「未确证未参与 v2 训练」——它甚至不是一个
   干净的 held-out 集。其余迁移矩阵格子为 N/A（缺数据或缺配对产物）。
2. **PHQ-9 数据集 682 行 [S-04] 未进入任何指标计算。** 原始数据不在版本库、无 json
   工件记录行数，只作规模陈述；这与「无逐条目标注」的既有审计结论一致（该 csv 仅
   总分，无文本列），证据链监督方向无标签支撑。
3. **OOD(strict) 子集 2523 行 [S-03] 的同源污染已被证明而非假设。** 其构造记录显示
   1275 条 original 全在训练语料、1175 条 mmpsy_augmented 全在训练增强集中；所谓
   「严格不重叠」只是相对训练语料的精确去重，不能替代真正独立采集的数据。
4. **groupwise 语料 8379 行 [S-05] 只覆盖文本模态**，生理模态没有同等的分组 held-out
   方案（生理数据无稳定的 user_id 分组语义）。

## 2. 模型与算法层面的局限

1. **生理模态只有域内证据。** 域内 ROC AUC 0.9451 [C-05] 不能外推到其他设备或人群；
   跨设备迁移失败且与随机不可区分（Kaggle Wearable 上 AUC 0.5120 [C-12]，
   95% CI [0.5006, 0.5233] 覆盖 0.5；Accuracy 0.4801 [C-10]、F1 0.3639 [C-11]）。
2. **文本模态的强读数全部是泄漏口径。** F1 0.9862 [C-19] 按泄漏证据处理；真泛化
   上界是 groupwise F1 0.5864 [C-22]，绝对值不高，且与生理模态不可比。
3. **生产融合层对冲突样本的定级敏感于权重标定。** 翻转点恰在生产权重 0.55 处
   [X-04、X-05]；但敏感性扫描只基于 5 组手写场景 [X-01 ~ X-06]，无统计效力。
4. **阈值 0.5 是既定部署口径，不是优化结果。** 在 n = 157 上做阈值挑优会直接构成
   泄漏（阈值挑优禁令见泄漏审计报告），因此本文不报告任何「更优阈值」。

## 3. 样本量层面的局限

1. **域内测试集 n = 157、阳性仅 55 例**（混淆矩阵 TP=48 / FP=14 / FN=7 / TN=88 [C-06]），
   Recall 0.8727 [C-03] 的 95% CI 宽约 0.17，Accuracy 0.8662 [C-01] 的 CI 亦宽约 0.11。
   域内正向结论只是中等强度；本文一律附 CI、不报裸点估计。
2. **bootstrap B = 10000（seed = 42）不解决小样本的结构性不确定性**：CI 宽是样本量
   的后果，增加 B 只会让区间估计更稳，不会让区间变窄。
3. **负向结论的样本量是够的**：迁移失败在 n = 10000 [S-02] 上成立；但「未测试」的
   格子（其余 16 格迁移矩阵）不代表通过。

### 3bis. 校准分析层面的局限（ROUND_33 新增）

4. **校准读数的样本量比阈值读数更吃紧**。主口径（文本 groupwise OOF，n = 8379）
   的 Brier CI 宽约 0.019 [C-26]、ECE CI 宽约 0.036 [C-27]，尚可支撑「方向性」结论；
   但生理单元的校准读数来自 n = 157 [C-29]（ECE 0.2160、CI 宽约 0.083），**只能作
   次级参考**，本文在任何引用处都同句标注 n = 157。
5. **校准斜率/截距未给 CI**（C-28 的 CI 单元格为「—」）：每次 bootstrap 都需重跑
   一次优化，成本不成比例；且其解释价值在「偏离 1 的方向」而非区间宽度。本文只用
   它支撑「概率偏保守」这一定向判断，不用它做任何定量外推。
6. **决策曲线（DCA）只报点估计**，未给净获益的 CI；阈值区间 [0.03, 0.99] 等
   描述的是「在本批数据上成立」，不构成跨人群保证。
7. **没有做校准后处理**（Platt / isotonic 重拟合）。重拟合需要独立留出集，而
   生理单元 n = 157、文本 OOF 已用尽，均不满足该前提；故本文只诊断不修复。
   「校准后能到什么水平」本文不作任何声明。
8. **阈值下调的收益没有实测**：§4ter.1 只论证「方向上值得下调」，未扫描阈值，
   不声称「下调到 0.2 可把 Recall 提到 X」。

### 3ter. 漏报安全网层面的局限（ROUND_36 新增）

9. **双阈值规则的成本与单阈值下调恒等**：需人工介入比例只由 `t_low` 决定
   （= P(p≥t_low)，已数值核验），`t_high` 只改预警/复核分配。因此「安全网」
   相对「直接下调阈值」的唯一增益是**预警队列精确率更高**（0.6815 [C-37] vs 0.2620 [C-38]），
   **不是成本更低**。任何把双阈值当作「省钱方案」的解读都与数据相反。
10. **单独使用文本模态做漏报安全网在成本上不成立**：净 Recall 0.9845 [C-34] 的
    代价是 0.8125 [C-35] 的样本进入人工流程，接近全员初筛。根因是文本概率在
    低分区间信息量不足（该区间阳性率 0.1905 [C-36] 低于基准率 0.2163）。
    可行的安全网应做在融合层（叠加生理/结构化信号），本文未做。
11. **工作点无独立验证**：全部样本都是 OOF，不存在第二份数据可验证扫出的
    工作点 ⇒ 带选择性偏差，不得宣称为「已验证的最优阈值」。

### 3quater. 融合消融层面的局限（ROUND_37 新增）

12. **端到端融合消融没有数据基础**：三模态不对齐（文本来自 MMPsy 学生 8379 行、
    生理来自 depresjon 157 行、结构化母表是 PHQ-9 且即训练标签母体），三方人群不同。
    本轮只在**确定性分数网格**上验证融合层规则行为，**不构成任何模态的性能或
    贡献度证据**；要评估真实融合性能，必须先有三模态对齐数据。
13. **合成网格的覆盖有限**：步长 10 的 11³ 网格只覆盖整数十分位，`t_high` 边界
    附近的精细行为未扫（消融只改模态集合、不改阈值表，故影响限于等级映射层）。
14. **未改生产代码**：本轮给出「单模态请求应降级处理」的依据，但没有实现该降级；
    在实现前，仅剩生理模态的请求会把 0.15 权重的模态放大成唯一决策者
    （冲突层翻转率 0.86 [X-08]、最大 4 级 [X-09]）。

## 4. 缺陷披露与整改状态（P0）

1. **生产 scaler 与模型权重不配套（D-R26-1）：ROUND_29 已修复，本节留档。** 修复前
   它把生产 Recall 压至 0.6000 [C-03]（TP=33 / FP=0 / FN=22 / TN=102，历史口径）；
   旧权重下的诊断对照为 F1 0.9369 [C-07]、Recall 0.9455 [C-08]、ROC AUC 0.9841 [C-09]
   （均为历史口径，不得宣称为性能）。ROUND_29 按路径 B 端到端重训后，同一测试集上
   Recall 0.8727 [C-03]、F1 0.8205 [C-04]、AUC 0.9451 [C-05]；修复后 AUC 由 0.9884
   （历史口径）降至 0.9451，说明这是**标准化缺陷整改而非能力提升**。修复后工件与
   防复发闸门（`tests/test_p2_56_round29_scaler_consistency.py`，三层判据 + 6/6
   变异臂见证）详见 `docs/P2_56_ROUND29_SCALER_FIX_AUDIT.md`。**该缺陷的教训仍然
   成立：修复后读数同样不得当作「模型能力上限」。**
2. **不可复现的历史读数仍在仓内流通**（样本量 n=139 的一组、registry 的第三套数字、
   bootstrap 均值误记），已列入黑名单 B-01 ~ B-03。它们不影响本论文数字，但读者
   翻阅旧文档时会遇到——论文侧只作拒绝性标注，不删除历史文件。
3. **`/health/startup` 在 Sentry 初始化失败时误记 ok**（第二十七批发现）已由
   ROUND_39 关闭：`init_sentry` 返回 bool + `SKIPPED` 哨兵，未配置 DSN / SDK
   不可用时记 `skipped`；与论文数字无关，保留本条作为历史记录。
