## Q1. 域内 ROC AUC 0.9451 [C-05]，为什么论文不主张泛化？

因为 AUC 只度量**同一测试分布内部**的排序能力，而泛化是跨分布问题，两者不是同一件事。
本文的泛化证据全部来自跨数据集实验，结论为负：生理 × Kaggle Wearable 的 ROC AUC
仅 0.5120 [C-12]，其 95% CI [0.5006, 0.5233] 覆盖 0.5，与随机不可区分；文本模态
唯一可引用的泛化口径是 groupwise 划分下的 F1 = 0.5864 [C-22]，低于同分布读数。
域内 AUC 与 Recall 0.8727 [C-03] 之间的差距同时说明：瓶颈在阈值位置与样本量，不在
排序结构（缺陷整改记录见 Q2）。在只有负迁移证据的情况下主张泛化，属于没有证据支撑的外推。

## Q2. Recall 从修复前的 0.60 到修复后的 0.8727 [C-03]，这个提升是模型变强了吗？

**不是，这是修标准化缺陷，不是能力提升。** 修复前（存档口径，不可比）生产链路的
scaler 与模型权重、训练数据三者不同源：同一 n = 157 测试集上 Recall 仅 0.6000 [C-03 修复前口径]
（TP=33 / FP=0 / FN=22 / TN=102）。ROUND_29 按路径 B 端到端
重训（cleaner/scaler 只在 train 719 行上拟合、模型经该 scaler 训练，co-consistent
by construction），修复后 Recall 0.8727 [C-03]、F1 0.8205 [C-04]、AUC 0.9451 [C-05]。
判据是：修复后 AUC 由修复前的 0.9884（历史口径）**下降**到 0.9451 [C-05]——没有任何
能力读数变好，变回来的是「生产链路与训练一致」。修复前旧权重的诊断读数（Recall
0.9455 / F1 0.9369 / AUC 0.9841，历史口径，不得宣称为性能）不得作为性能引用；修复后
单切分 0.8727 [C-03] 也**低于**该诊断读数，本文不追这个数（在测试集上调参即泄漏）。
新管线重复 CV（5 折 × 3 次，与 provenance 诊断同折）Recall 0.88 ± 0.04。因此当前
0.8727 [C-03] 只是「缺陷修复后的实测」，在抑郁筛查场景仍不构成「筛查就绪」结论。

## Q3. n = 157 的样本量，结论可靠吗？

分两类结论看。**负向结论可靠**：生理跨设备迁移失败在 n = 10000 [S-02] 上复现
（AUC 0.5120 [C-12]，CI 覆盖 0.5），大样本让「与随机不可区分」成为硬结论。
**域内正向结论只是中等强度**：n = 157 中阳性仅 55 例，Recall 的 CI 宽约 0.17
[C-03]，Accuracy 0.8662 [C-01] 的 CI 也宽约 0.11；因此本文所有指标一律附
bootstrap 95% CI（B = 10000，seed = 42），不报裸点估计。文本侧另有一个
n = 8379 [S-05] 的 groupwise 交叉验证（F1 0.5864 [C-22]）作为不同样本量下的
交叉参考，但其语料与生理模态不可比。

## Q5. 文本模态 F1 0.9862 [C-19] 是不是刷分？

是，论文按泄漏证据处理，并强制与真泛化口径同引。该 OOD(strict) 子集的构造本身
来自泄漏审计：1275 条 original 全在训练语料、1175 条 mmpsy_augmented 全在训练
增强集中；同一模型随机划分下的读数 0.9964（台账 C-22 备注）与 0.9862 同属
同源近重复导致的虚高。文本模态唯一可引用的泛化读数是按 user_id 分组、组间不重叠的
groupwise 交叉验证 F1 = 0.5864 [C-22]。两者相差约 0.40，即「同源泄漏」与
「真泛化」的差距；单独引用 0.9862 [C-19] 而隐去 0.5864 [C-22] 在本文纪律下不允许。

## Q6. 为什么全文没有任何一个正向的跨数据集迁移结果？

因为实测没有。两个可运行单元全部为负或不可用：生理 → Kaggle Wearable 迁移失败
（Accuracy 0.4801 [C-10]、F1 0.3639 [C-11]、AUC 0.5120 [C-12]，CI 覆盖 0.5），
且该数据集「未确证未参与训练」（其评估 json 的 dataset.note 原文如此）；文本 →
OOD 的高指标是泄漏证据（Q5）。其余迁移矩阵格子为 N/A：缺数据或缺配对产物。
生理信号强设备相关（采集设备、佩戴方式、采样率差异），线性文本模型对同源近重复
过敏感——两者都没有给出正向外推的证据，论文如实写 0 个真外迁单元。

## Q8. 融合权重敏感性结论能外推到生产配置吗？

只能定性外推。扫描覆盖生产权重 0.55/0.3/0.15 [X-06]：仅当模态结论冲突时风险等级
对权重敏感，且翻转点恰在生产权重处（2→1 @0.55 [X-04]、2→3 @0.55 [X-05]）；
三组一致场景（agree_low / agree_high / mid_all）在全部 9 行权重下等级不变
[X-01 ~ X-03]。但输入是 5 组**手写**场景，其历史「全 1.0000」行已叙事禁用
[B-04]——该扫描说明融合层定性行为，不构成性能证据，不能据此声称生产定级稳健。

## Q9. 校准斜率 1.3466 [C-28] 大于 1，是不是说明模型过自信？

**恰好相反，是偏保守（欠自信）。** Platt 缩放拟合的是 `logit(p) = intercept + slope · logit(p_pred)`：
斜率大于 1 表示真实结果在 logit 尺度上的变化比预测概率更大，即**预测概率被压向中间、
离散度不足**。配合截距 −0.3541 [C-28] 的整体下偏，这与阈值读数自洽——正因为概率偏低，
固定阈值 0.5 才漏掉约 46% 的阳性（Recall 0.5375 [C-24]）。

若模型过自信（预测概率过于极端，如大量 0.99 / 0.01 而实际远达不到），斜率会**小于** 1。
本文里真有这样的例子：生理模型跨到 Kaggle 后斜率跌到 0.1356 [C-30]——那正是过自信到
失去区分度的形态，与 AUC 0.5120 [C-12] = 随机水平互为印证（该单元为压力测试口径，禁作外迁引用）。

斜率/截距**没有 CI**（C-28 的 CI 单元格为「—」，理由见 `RESULTS_CHAPTER.md` §4ter.4），
故本结论只作方向性判断，不作定量外推。

## Q10. 决策曲线（DCA）支持「用模型替代人工」吗？

**不支持，它支持的是「用模型筛一道再人工复核」。** 在主口径上（文本 groupwise OOF，
n = 8379），模型的净获益在阈值 [0.03, 0.99] 区间优于「全员干预」、在 [0.01, 0.68]
优于「不干预」；代表点如 t = 0.50 时模型净获益 0.0523 [C-32]，而「全员干预」为 −0.5675。
这说明**筛一道比不筛、也比全筛都好**，但不等于筛出来就不需要人看——DCA 的
「干预」在本场景里应理解为「进入人工复核队列」，而非「确诊」或「自主处置」。

两点必须同时说：(1) 低阈值端（t ≤ 0.05）模型仅与「全员干预」持平（0.1763 [C-33] vs 0.1750），
增量价值很薄；(2) DCA 只报点估计、未给 CI（`RESULTS_CHAPTER.md` §4ter.4），
阈值区间描述的是「在本批数据上成立」，不构成跨人群保证。
