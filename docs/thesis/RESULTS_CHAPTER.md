## 1. 实验设置

**样本量（先于任何指标给出）**：生理域内测试集 n = 157（depresjon 数据集 1029 行，
按 719 / 153 / 157 做分层划分）；生理跨数据集迁移用 Kaggle Wearable 数据 10000 行；
文本模态 OOD(strict) 压力测试 2523 行；文本 groupwise 泛化口径语料 8379 行；
另有一个 PHQ-9 数据集 682 行，仅作数据集规模陈述（台账 S-04），不关联任何指标——
其原始数据不在版本库、无 json 工件记录行数，不可复算。

**生产推理链（被评估对象即上线链路，无额外后处理）**：

- 生理模态：清洗（既定缺失值策略）→ 标准化（生产 artifact 的 scaler 参数）→ MLP → 概率分；
- 文本模态：TF-IDF 特征 + 线性分类器 → 概率分；
- 融合层：三模态概率分按生产默认权重（结构化 0.55 / 文本 0.30 / 生理 0.15，
  台账 X-06，源码 AST 取值）加权平均，再按融合档阈值 22 / 42 / 62 / 82 分档。

**评估口径**：判定阈值 0.5（三个评估单元的 `json.threshold` 一致，闸门逐条断言）；
点估计为全样本统计量；95% CI 为非参数 bootstrap 分位区间（B = 10000，seed = 42），
逐样本预测 csv 已随评估 json 一并提交，复算严格按 csv 落盘行序进行（ROUND_27 教训）。

## 2. 域内结果（生理模态 · 生产路径）

域内测试集 n = 157 上的主结果如下（台账 C-01 ~ C-06；CI 为 bootstrap 95% 分位区间）：

| 指标 | 点估计 | 95% CI |
|---|---|---|
| Accuracy | 0.8599 | [0.8025, 0.9108] |
| Precision | 1.0000 | [1.0000, 1.0000] |
| Recall | 0.6000 | [0.4717, 0.7292] |
| F1 | 0.7500 | [0.6410, 0.8434] |
| ROC AUC | 0.9884 | [0.9699, 0.9990] |

域内混淆矩阵：TP=33 / FP=0 / FN=22 / TN=102（台账 C-06；阳性 55 例、阴性 102 例）。

**诚实解读（必须与主表同读）**：

1. **区间宽是样本量的结构性后果，不是模型缺陷的度量**。n = 157、其中阳性仅 55 例，
   Recall 的 95% CI 宽达约 0.26（[0.4717, 0.7292]）；同类研究在此量级样本上报告
   点估计时若不附区间，会系统性高估置信度。本文所有指标一律附 CI。
2. **Recall 0.60 意味着漏报 22/55 例阳性**。在抑郁筛查这类「漏报代价高」的场景里，
   0.60 的 Recall 不能直接作为可用阈值；它同时受 §3 所述 P0 缺陷压制，两者不可混为一谈。
3. **Precision = 1.0000 与 ROC AUC = 0.9884 的差距是阈值位置的产物**：排序能力（AUC）
   远好于固定阈值 0.5 下的分类表现，说明阈值选择（而非排序）是当前瓶颈之一；
   但受样本量限制，本文不主张存在更优的可复现阈值（挑优即泄漏，见台账 B-05 与
   泄漏审计报告的阈值挑优禁令）。
4. 本文**不主张**基于该表做任何跨人群、跨设备的性能外推——外推证据见 §4，全部为负。

## 3. P0 缺陷披露（生产 scaler 与模型不配套）

**这是本轮评估发现的最严重缺陷，按学术诚信要求全文披露，不得隐藏。**

生产链路的标准化参数（artifact 的 scaler）与当前模型权重、当前训练数据三者不同源：
在 n = 157 测试集上，生产路径的 Recall 仅 0.6000。为定位问题所在，做了一项诊断实验
——只把标准化参数换成「在当前训练集上重新拟合」的 scaler，其余（模型权重、特征、
阈值）完全不变：

| 链路 | F1 | Recall | ROC AUC |
|---|---|---|---|
| 生产路径（artifact 自带 scaler） | 0.7500 | 0.6000 | 0.9884 |
| 诊断对照（当前训练集重拟合 scaler） | 0.9369 | 0.9455 | 0.9841 |

三点结论：

1. **问题在标准化参数，不在模型排序能力**：两行的 ROC AUC 几乎相同（0.9884 vs 0.9841，
   台账 C-05 / C-09），说明模型学到的排序结构是好的；F1/Recall 的巨大差异来自
   scaler 不配套对分数分布的整体平移，把本应过阈值的样本压到了阈值以下。
2. **待整改缺陷不得作为模型能力宣称**：0.9369 / 0.9455 只是诊断读数（台账 C-07 / C-08，
   备注「仅用于缺陷定位」），不是生产链路的性能，不得写入结论或摘要；
   生产口径的唯一合法读数就是 §2 主表。
3. **整改状态**：本缺陷编号 D-R26-1，截至本轮**未修复**（ROUND_28 边界：不修缺陷、
   不重训、不改推理）。历史口径中另有一组样本量 n=139 的生理读数，因不可复现
   （划分、scaler 统计量、训练脚本三重证据不符）已列入黑名单 B-01，本文一律不引用。

## 4. 跨数据集迁移

**结论先行：0 个单元构成真正的外部迁移成功。** 两个可运行的降级单元结果如下
（台账 C-10 ~ C-15、C-16 ~ C-21；「降级」指定性：这些读数是能力下界/压力测试，
不是泛化主张）：

| 单元 | n | F1 [95% CI] | ROC AUC [95% CI] | 混淆矩阵 TP/FP/FN/TN | 定性 |
|---|---|---|---|---|---|
| 生理 × Kaggle Wearable | 10000 | 0.3639 [0.3507, 0.3772] | 0.5120 [0.5006, 0.5233] | 1487 / 1529 / 3670 / 3314 | 降级：AUC 的 95% CI 覆盖 0.5，与随机不可区分 |
| 文本 × OOD(strict) | 2523 | 0.9862 [0.9783, 0.9930] | 0.9986 [0.9956, 0.99999] | 499 / 0 / 14 / 2010 | 降级：域内压力测试，高指标是泄漏证据 |

1. **生理 → Kaggle Wearable：迁移失败，且与随机不可区分。** ROC AUC 0.5120 的 CI
   [0.5006, 0.5233] 覆盖 0.5（台账 C-12 备注即此判据）；Accuracy 0.4801 低于多数类
   基线。可穿戴设备间的生理信号迁移未得到任何证据支持。
2. **文本 → OOD：0.9862 的高指标必须按泄漏证据解读，不得当作泛化。** 该子集的构造
   本身即泄漏审计的结论：1275 条 original 全在训练语料、1175 条 mmpsy_augmented
   全在训练增强集中，仅保留精确不重叠的 2523 条后读数依然极高——说明同源近重复
   足以让线性文本模型在「未见设备/未见采集批次」上刷分。兄弟泄漏的进一步证据：
   同一模型在随机划分下的读数是 0.9964（台账 C-22 备注），与 0.9862 同属泄漏口径。
3. **文本模态唯一可引用的「泛化」读数是 groupwise 口径**：按 user_id 分组切分、
   组间不重叠的交叉验证下，F1 = 0.5864（台账 C-22，n = 8379，阈值 0.5）。
   它与 0.9862 之间约 0.40 的差，就是「同源泄漏」与「真泛化」的差。
4. 因此，本文对跨数据集迁移的全部主张为：**生理迁移失败（与随机不可区分），
   文本高指标不构成泛化证据，真泛化上界为 groupwise F1 0.5864。**

## 5. 融合权重敏感性（补充材料）

融合层按 5 组手写场景（三模态分数固定）、以结构化权重 0.35–0.75 扫描
（w_text : w_physio 恒为 2:1，权重和 = 1）得到 `fusion_weight_sensitivity.csv`
（45 行，生成脚本未入库 ⇒ 闸门复算其内部一致性：加权平均公式 + 22/42/62/82
分档 + 生产权重行存在）。台账 X-01 ~ X-06：

| 场景 | 权重敏感性结论 |
|---|---|
| agree_low（20/15/18） | 0 级（9/9 行）：低分一致时不敏感 |
| agree_high（85/90/88） | 4 级（9/9 行）：高分一致时不敏感 |
| mid_all（50/55/52） | 2 级（9/9 行）：中档一致时不敏感 |
| conflict_s-low_t-high（20/90/25） | 2→1 级 @0.55：结构化权重增大时风险等级下调 |
| conflict_s-high_t-low（85/15/80） | 2→3 级 @0.55：结构化权重增大时风险等级上调 |
| 生产权重（0.55/0.3/0.15） | 在扫描范围内，结论适用于生产配置 |

解读：仅在模态结论冲突时，融合结果对权重敏感；翻转点恰好落在生产权重 0.55 处，
说明生产配置下冲突样本的风险定级对权重标定是敏感的——但该敏感性扫描是 5 条
**手写**场景（台账 B-04 已叙事禁用其「全 1.0000」历史行），只用于说明融合层的
定性行为，不构成性能证据。

## 7. 结论

在域内测试集 n = 157 上，生理模态生产链路达到 F1 0.7500 [0.6410, 0.8434]、
ROC AUC 0.9884 [0.9699, 0.9990]，但 Recall 仅 0.6000 [0.4717, 0.7292]，
且已定位其主因为生产 scaler 与模型不配套（P0，未修复，§3）。跨数据集方面，
生理→可穿戴迁移与随机不可区分（AUC 0.5120，CI 覆盖 0.5），文本→OOD 的 0.9862
为同源泄漏证据，文本模态真泛化上界为 groupwise F1 0.5864。本文不主张任何
跨设备、跨人群的部署就绪结论；缺陷整改与更大样本的外部验证是后续工作的前提。
