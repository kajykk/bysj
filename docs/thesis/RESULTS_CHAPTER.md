## 1. 实验设置

**样本量（先于任何指标给出）**：生理域内测试集 n = 157（depresjon 数据集 1029 行，
按 719 / 153 / 157 做分层划分）；生理跨数据集迁移用 Kaggle Wearable 数据 10000 行；
文本模态 OOD(strict) 压力测试 2523 行；文本 groupwise 泛化口径语料 8379 行；
另有一个 PHQ-9 数据集 682 行，仅作数据集规模陈述（台账 S-04），不关联任何指标——
其原始数据不在版本库、无 json 工件记录行数，不可复算。

**生产推理链（被评估对象即上线链路，无额外后处理）**：

- 生理模态：清洗（既定缺失值策略）→ 标准化（生产 artifact 的 scaler 参数；ROUND_29 起
  与训练同源，co-consistent by construction）→ MLP → 概率分；
- 文本模态：TF-IDF 特征 + 线性分类器 → 概率分；
- 融合层：三模态概率分按生产默认权重（结构化 0.55 / 文本 0.30 / 生理 0.15，
  台账 X-06，源码 AST 取值）加权平均，再按融合档阈值 22 / 42 / 62 / 82 分档。

**评估口径**：判定阈值 0.5（三个评估单元的 `json.threshold` 一致，闸门逐条断言）；
点估计为全样本统计量；95% CI 为非参数 bootstrap 分位区间（B = 10000，seed = 42），
逐样本预测 csv 已随评估 json 一并提交，复算严格按 csv 落盘行序进行（ROUND_27 教训）。

## 2. 域内结果（生理模态 · 生产路径）

域内测试集 n = 157 上的主结果如下（台账 C-01 ~ C-06；ROUND_29 修复 D-R26-1 后的
生产链路；CI 为 bootstrap 95% 分位区间）：

| 指标 | 点估计 | 95% CI |
|---|---|---|
| Accuracy | 0.8662 | [0.8089, 0.9172] |
| Precision | 0.7742 | [0.6667, 0.8750] |
| Recall | 0.8727 | [0.7800, 0.9531] |
| F1 | 0.8205 | [0.7387, 0.8889] |
| ROC AUC | 0.9451 | [0.9064, 0.9768] |

域内混淆矩阵：TP=48 / FP=14 / FN=7 / TN=88（台账 C-06；阳性 55 例、阴性 102 例）。

**诚实解读（必须与主表同读）**：

1. **区间宽是样本量的结构性后果，不是模型缺陷的度量**。n = 157、其中阳性仅 55 例，
   Recall 的 95% CI 宽达约 0.17（[0.7800, 0.9531]）；同类研究在此量级样本上报告
   点估计时若不附区间，会系统性高估置信度。本文所有指标一律附 CI。
2. **Recall 0.8727 意味着漏报 7/55 例阳性**。在抑郁筛查这类「漏报代价高」的场景里，
   该读数不能直接作为可用阈值；它是 ROUND_29 修复生产 scaler 缺陷**之后**的实测
   （修复前同一测试集上为 0.6000，历史口径，见 §3），两者不可混为一谈。
3. **Precision 0.7742 与 ROC AUC 0.9451 的差距是阈值位置的产物**：排序能力（AUC）
   仍好于固定阈值 0.5 下的分类表现，说明阈值选择是当前瓶颈之一；
   但受样本量限制，本文不主张存在更优的可复现阈值（挑优即泄漏，见台账 B-05 与
   泄漏审计报告的阈值挑优禁令）。
4. 本文**不主张**基于该表做任何跨人群、跨设备的性能外推——外推证据见 §4，全部为负。

## 3. P0 缺陷披露与 ROUND_29 修复记录（修标准化缺陷，不是模型变强）

**缺陷（修复前，存档口径）**：生产链路的标准化参数（artifact 的 scaler）与模型权重、
训练数据三者不同源：在 n = 157 测试集上，修复前生产路径 Recall 仅 0.6000
（TP=33 / FP=0 / FN=22 / TN=102，历史口径，不可比）。为定位问题，ROUND_26 做过一项
诊断实验——只把标准化参数换成「在当前训练集上重新拟合」的 scaler，其余不变：
Recall 0.9455 / F1 0.9369 / AUC 0.9841（旧权重下的诊断读数，仅用于定位缺陷，
不得宣称为性能，历史口径）。

**修复（ROUND_29 · 路径 B 端到端重训）**：诊断同时表明「只换 scaler」不够——旧权重
与当前数据不稳健兼容（旧权重在新数据上的重复 CV：recall 0.8729±0.0342，强依赖切分）
——故端到端重训：cleaner/scaler 只在 train 719 行上拟合，模型经该 scaler 训练
（co-consistent by construction），超参数沿用 `metrics.json` 记录值（不为迁就测试集
调参），固定 seed 42，同 seed 两跑产物逐字节一致；修复前工件存档为
`*.broken_round29`。防复发闸门 `tests/test_p2_56_round29_scaler_consistency.py`：
第一层可复现性（部署 scaler == train-only 重拟合，实测 max|diff| = 0.000e+00）、
第二层域合理性、结构层；变异见证 6/6 臂红
（`backend/tests/tools/mutate_p2_56_round29.py`）。

**修复后（同一测试集、同一阈值 0.5）**：Recall 0.8727、F1 0.8205、ROC AUC 0.9451
（台账 C-03 / C-04 / C-05）。一致性证明：csv 的 `y_score_refit_scaler` 列
（train-only 独立重拟合过**同一套生产权重**）与 `y_score` **逐位相等**——

| 链路 | F1 | Recall | ROC AUC |
|---|---|---|---|
| 生产路径（部署 artifact，co-consistent by construction） | 0.8205 | 0.8727 | 0.9451 |
| 诊断对照（train-only 独立重拟合；ROUND_29 后与生产逐位相等） | 0.8205 | 0.8727 | 0.9451 |

**为什么这是修缺陷、不是模型变强**：修复后 ROC AUC 由修复前的 0.9884 **下降**到
0.9451——修复没有提高任何能力读数，它只是把生产链路换回与训练一致的标准化，使阈值
0.5 重新有意义；修复前的高 AUC 是错配标准化下的读数，与修复后不可比。另如实记账：
修复后单切分 Recall 0.8727 **低于**修复前旧权重的诊断读数 0.9455——本文不追这个数
（在测试集上调参即泄漏，台账 B-05）；新管线重复 CV（5 折 × 3 次，与 provenance
诊断同折）Recall 为 0.88 ± 0.04，与单切分点估计同量级（逐折明细见
`docs/P2_56_ROUND29_SCALER_FIX_AUDIT.md`）。

## 4. 跨数据集迁移

**结论先行：0 个单元构成真正的外部迁移成功。** 两个可运行的降级单元结果如下
（台账 C-10 ~ C-15、C-16 ~ C-21；「降级」指定性：这些读数是能力下界/压力测试，
不是泛化主张）：

| 单元 | n | F1 [95% CI] | ROC AUC [95% CI] | 混淆矩阵 TP/FP/FN/TN | 定性 |
|---|---|---|---|---|---|
| 生理 × Kaggle Wearable | 10000 | 0.3639 [0.3507, 0.3772] | 0.5120 [0.5006, 0.5233] | 1487 / 1529 / 3670 / 3314 | 降级：AUC 的 95% CI 覆盖 0.5，与随机不可区分 |
| 文本 × OOD(strict) | 2523 | 0.9862 [0.9783, 0.9930] | 0.9986 [0.9956, 0.99999] | 499 / 0 / 14 / 2010 | 降级：域内压力测试，高指标是泄漏证据 |

1. **生理 → Kaggle Wearable：迁移失败，且与随机不可区分。** ROC AUC 0.5120 的 CI
   [0.5006, 0.5233] 覆盖 0.5（台账 C-12 备注即此判据）；Accuracy 0.4801 低于多数类
   基线。可穿戴设备间的生理信号迁移未得到任何证据支持。
2. **文本 → OOD：0.9862 的高指标必须按泄漏证据解读，不得当作泛化。** 该子集的构造
   本身即泄漏审计的结论：1275 条 original 全在训练语料、1175 条 mmpsy_augmented
   全在训练增强集中，仅保留精确不重叠的 2523 条后读数依然极高——说明同源近重复
   足以让线性文本模型在「未见设备/未见采集批次」上刷分。兄弟泄漏的进一步证据：
   同一模型在随机划分下的读数是 0.9964（台账 C-22 备注），与 0.9862 同属泄漏口径。
3. **文本模态唯一可引用的「泛化」读数是 groupwise 口径**：按 user_id 分组切分、
   组间不重叠的交叉验证下，F1 = 0.5864（台账 C-22，n = 8379，阈值 0.5）。
   它与 0.9862 之间约 0.40 的差，就是「同源泄漏」与「真泛化」的差。
4. 因此，本文对跨数据集迁移的全部主张为：**生理迁移失败（与随机不可区分），
   文本高指标不构成泛化证据，真泛化上界为 groupwise F1 0.5864。**

## 4bis. 文本模型跨被试真实泛化（真实效果）

**样本量与协议（先于指标）**：语料 8379 条、**1277 个原始用户（学生）**、阳性率 21.6%。
协议为 sibling-aware 分组去泄漏：同一学生的原文与其全部增强副本（同义替换 / 回译）
归入同一组，`StratifiedGroupKFold`×5 每折重训同规格 TF-IDF+LR、在**未见的组**上评估
（OOF 逐样本预测已落盘 `backend/scripts/modeling/v1_27/groupwise_oof_predictions.csv`，
sha256 `0dd48b4a…`）。95% CI 为**按 group 重采样**的分组级 bootstrap（抽 1277 组、
B=10000、seed=42，非按行——组内相关，按行会低估区间；台账 C-22 ~ C-25，`groupwise_ci.json`）。

| 指标 | 点估计 | 95% CI（按用户分组） |
|---|---|---|
| F1（跨被试） | 0.5864 | [0.5307, 0.6381] |
| ROC AUC（跨被试） | 0.8437 | [0.8170, 0.8696] |
| Recall（跨被试） | 0.5375 | [0.4764, 0.5975] |
| Precision（跨被试） | 0.6450 | [0.5782, 0.7114] |

**对照口径与虚高幅度**：同一语料、同一模型，若按**随机划分**（行级，增强副本可跨
训练/测试）评估，F1 = 0.9964、AUC = 0.9994——这是兄弟泄漏口径。分组口径相对随机
口径的落差为 **F1 −0.41、AUC −0.156**，这 −0.41 即「同源泄漏 + 数据增强」制造的
虚高幅度，是本文最重要的方法学结论之一。

**范围内涵（不得外推）**：

1. **这是「同人群、换被试」的泛化，不是「跨平台/跨人群」**：语料全部来自 MMPsy 同一
   招募的学生群体，分组只保证测试用户未参与训练，不保证跨采集平台、跨语言、跨人群。
   跨平台/跨人群泛化需真正外部数据（本文不含，见 §4 与 §7）。
2. **模型有真实信号，但偏弱**：AUC 0.8437 的 95% CI [0.8170, 0.8696] 显著高于 0.5
   （对比生理→可穿戴迁移的 AUC 0.5120 = 随机），说明换一批新用户时文本模态仍有判别力；
   但 F1 0.5864、Recall 0.5375 意味着在阈值 0.5 下**漏掉约 46% 的阳性**。
3. **定位为辅筛信号，非自主筛查**：Recall 0.5375 在抑郁筛查场景不可作为独立判据，
   只能作为「辅助初筛 + 人工复核」的一个信号源；任何据此的自主决策都不被本文支持。

## 5. 融合权重敏感性（补充材料）

融合层按 5 组手写场景（三模态分数固定）、以结构化权重 0.35–0.75 扫描
（w_text : w_physio 恒为 2:1，权重和 = 1）得到 `fusion_weight_sensitivity.csv`
（45 行，生成脚本未入库 ⇒ 闸门复算其内部一致性：加权平均公式 + 22/42/62/82
分档 + 生产权重行存在）。台账 X-01 ~ X-06：

| 场景 | 权重敏感性结论 |
|---|---|
| agree_low（20/15/18） | 0 级（9/9 行）：低分一致时不敏感 |
| agree_high（85/90/88） | 4 级（9/9 行）：高分一致时不敏感 |
| mid_all（50/55/52） | 2 级（9/9 行）：中档一致时不敏感 |
| conflict_s-low_t-high（20/90/25） | 2→1 级 @0.55：结构化权重增大时风险等级下调 |
| conflict_s-high_t-low（85/15/80） | 2→3 级 @0.55：结构化权重增大时风险等级上调 |
| 生产权重（0.55/0.3/0.15） | 在扫描范围内，结论适用于生产配置 |

解读：仅在模态结论冲突时，融合结果对权重敏感；翻转点恰好落在生产权重 0.55 处，

**手写**场景（台账 B-04 已叙事禁用其「全 1.0000」历史行），只用于说明融合层的
定性行为，不构成性能证据。

## 7. 结论

在域内测试集 n = 157 上，生理模态生产链路（ROUND_29 修复 D-R26-1 标准化缺陷后）达到
F1 0.8205 [0.7387, 0.8889]、ROC AUC 0.9451 [0.9064, 0.9768]、Recall 0.8727
[0.7800, 0.9531]；该修复是校准缺陷整改而非能力提升（修复前生产 Recall 0.6000，
历史口径；修复后 AUC 反而由 0.9884 降至 0.9451）。跨数据集方面，生理→可穿戴迁移与
随机不可区分（AUC 0.5120，CI 覆盖 0.5），文本→OOD 的 0.9862 为同源泄漏证据，文本模态
真泛化上界为 groupwise F1 0.5864。本文不主张任何跨设备、跨人群的部署就绪结论；
更大样本的外部验证与阈值方案的预注册是后续工作的前提。
