# 人群证据矩阵（Phase 0）

> 日期：2026-11-02
> 范围：把「面向全人类」拆成可验证的人群范围问题。本文件只登记**已有证据**，
> 不把路线图写成现有能力；不修改模型、阈值、路由或生产产物。
> 配套：`MODEL_CARD_TEMPLATE.md`（人群感知模型卡模板与当前单元回填）、
> `DATASETS.md`（外部数据许可与取得状态）、`../ROUND_46_EVIDENCE.md`（离线读数）。

## 0. 结论先行

1. **当前系统不是全人群模型。** 四个推理单元各自只在特定人群/标签口径上有证据，
   而且其中三个（文本、生理、融合）连目标人群内的稳定泛化都未建立。
2. **结构化模型是唯一有跨来源读数的单元，但跨来源后明显退化。** 内部测试
   AUC 0.9131；干净 Kaggle→Mendeley 迁移 AUC 0.8633、Brier 0.1734、ECE 0.1435，
   0.5 阈值在目标域只报出约一半阳性。迁移同时混合了人群变化与标签定义变化。
3. **「全人群」不能靠换一个模型名实现。** 需要目标人群的标签定义对齐、目标域校准
   样本、分人群阈值/弃权策略和前瞻性验证。Phase 0 只建立披露与门禁，不做模型替换。
4. **没有任何现有公开数据同时具备「文本 + 可穿戴生理 + 抑郁标签 + 纵向随访」。**
   三模态融合单元因此标记为 `not_evaluable`，不得从合成分数网格推断性能。
5. **当前所有单元都禁止自动决策。** 运行时 `population_scope.automated_decision_allowed`
   一律为 `false`；风险分只能用于筛查排序与人工复核，不能作为自动诊断或自动处置依据。
6. **生理单元的训练特征不是真实测量。** `depresjon_physiological.csv` 可由转换脚本
   逐值复现：5/7 原始特征由真实队列标签驱动生成，另 1 个由其派生；仅真实 actigraphy
   派生列（steps/exercise）5 折 OOF AUC 为 0.6443。因此当前生理模型的 AUC 0.9451
   不能读作「真实生理信号识别抑郁」的能力，证据等级下调为 `synthetic_label_derived`。
   详见 `PHYSIO_DATA_PROVENANCE_AUDIT.md`。ROUND_47 已用 NHANES 2017–2018 做过迁移压力测试
   （AUC 0.5459），但标签/特征/协议同时改变，仍不构成外部验证，也不升级证据等级。

## 1. 判定规则

### 1.1 证据等级

| 等级 | 含义 | 可支持的结论 |
|---|---|---|
| `internal_source_split` | 同来源内部随机切分 | 只能支持「同来源同标签口径内的区分度」 |
| `groupwise_oof` | 按用户/来源分组、兄弟样本隔离的 OOF | 可支持「同来源内未见用户」的有限泛化 |
| `cross_source` | 跨数据集/跨采集协议留出 | 可支持「向该目标源的迁移」；不等于全人群 |
| `small_internal_split` | 同来源小样本、单次切分 | 只能作次级证据，CI 宽于结论 |
| `small_external` | 外部小样本、单次切分 | 只能作次级证据，CI 宽于结论 |
| `synthetic_label_derived` | 训练特征由标签驱动合成，内部指标主要反映合成映射 | 只能作管线一致性/回归读数；不能作为真实测量性能证据 |
| `not_evaluable` | 无对齐有标签样本 | 不能给出性能、模态贡献或阈值结论 |

### 1.2 允许自动决策的最低条件（当前无一单元满足）

一个单元要在某目标人群获得 `automated_decision_allowed=true`，至少要同时满足：

1. 目标人群的标签定义与训练标签一致（或已完成量表映射并通过一致性检验）；
2. 目标域有独立校准集，且标签数不少于 50（ROUND_46 conformal 报告给出的最低可行样本量）；
3. 目标域分组覆盖率达到名义值附近（建议缺口不超过 0.05），并报告组内覆盖率；
4. 关键亚组（年龄、性别、来源）的 TPR/FPR 差距及 CI 已报告且可接受；
5. 已接入人工复核/危机安全网，且自动处置有明确的申诉与回滚路径；
6. 训练与验证特征必须是真实测量或已登记的可接受代理，不得由标签驱动合成，
   否则内部指标不构成真实世界能力证据（生理单元即因此被下调）。

Phase 0 的运行时披露只完成第 5 项的一部分（人工复核标记与弃权提示），
前四项仍由 Phase 1 的外部迁移评估提供。

### 2.1 结构化：跨来源退化是联合迁移，不是单纯人群差异

- 训练母表：Kaggle 27,870 行（自报二分类，阳性率 0.5851）+ Mendeley 682 行
  （PHQ-9≥10，阳性率 0.4707），Mendeley `sample_weight=5.0x`。
- 特征分布差异：年龄 SMD +0.902、`panic_attack` SMD +1.302、`family_history` SMD +0.969；
  Mendeley 的 `family_history`/`panic_attack` 恒为 0、`cgpa` 恒为 3.0、`social_support` 全表恒为 2.0。
- `stress_level == academic_pressure` 比例 1.0000；`anxiety` 与 `stress_level` 相关 0.9868。
- 干净 Kaggle-only → Mendeley：平均预测概率 0.3272，实际阳性率 0.4707；0.5 阈值灵敏度约 0.511。
- 生产模型在内部测试的乐观偏差主要来自同源校准/阈值（F1 差 +0.1889），AUC 差仅 +0.0009。
- **人群结论**：当前证据只覆盖「学生/青年自报问卷」；对普通成人、临床人群、非英语人群
  均未验证。`cgpa`/`academic_pressure` 等学业特征本身也限制了非学生场景的适用性。

### 2.2 文本：唯一可引用的是 groupwise，不是 textwise

- 生产双语 TF-IDF+LR 已按 `user_id` 分组重训（`v1_27/04_retrain_bilingual_text_groupwise.py`）。
- sibling-aware groupwise OOF：n=8,379、1,277 组、阳性率 0.2163，AUC 0.8437、F1 0.5864。
- textwise OOF 的 AUC 0.9994 / F1 0.9950 是兄弟泄漏读数，不可引用；
  full-model 中文 0.9972 是 in-sample，也不可引用。
- 英文 holdout（同 Reddit 域）AUC 0.9877 只能说明同域跨语言保持，不是临床外部验证。
- **人群结论**：只支持中文学生文本的有限泛化；对普通成人、其他语言、临床访谈文本均无证据。

### 2.3 生理：训练特征由标签驱动合成，内部 AUC 不是真实生理性能

- Depresjon 队列 n=1,029，固定切分 test n=157（阳性率 0.3503），生产预测可逐样本复现。
- **来源审计（2026-11-02）**：`depresjon_physiological.csv` 的 8 个建模列可由
  `scripts/data_prep/convert_depresjon_to_system.py` 以 seed=42 逐值复现（8/8 列完全相等）。
  其中 `heart_rate`/`sleep_hours`/`sleep_quality`/`systolic_bp`/`diastolic_bp`
  由真实队列标签的分组均值 + 高斯噪声生成；`diastolic_bp` 又派生自 `systolic_bp`；
  `phq9_score` 也是标签的噪声副本（不是真实 PHQ-9）。只有 `steps` 与
  `exercise_minutes` 来自真实 actigraphy 汇总。
- **指标口径**：在同一 1,029 行上做 5 折 OOF 逻辑回归消融——
  仅真实 actigraphy 派生列为 **AUC 0.6443**；仅标签驱动合成列为 **AUC 0.9898**；
  当前 MLP test AUC 0.9451 落在合成列可解释范围内。
- 因此 AUC 0.9451 / F1 0.8205 只能作为「生产管线一致性/回归读数」，
  **不能**解释为真实心率、睡眠或血压对抑郁的识别能力，也不能与其他模态的真实外部读数并列。
- WESAD 只有应激/情感标签（stress vs baseline），不是抑郁标签；且缺少睡眠/血压等字段，
  不能作为本模型的外部验证集。
- **人群结论**：证据等级为 `synthetic_label_derived`；不得外推到普通人群、消费级可穿戴用户
  或临床诊断。真实生理模型需回到原始 actigraphy 特征重做（见审计 §6）。
- 审计与复现命令：`docs/model-evaluation/PHYSIO_DATA_PROVENANCE_AUDIT.md`。

### 2.4 融合：无对齐三模态有标签样本

- 现有模态数据来自不同人群、不同采集协议，且没有同一批受试者的三模态 + 抑郁标签。
- 融合权重敏感性分析只能说明「模态冲突时权重重要」，不能替代性能验证。
- **人群结论**：`not_evaluable`；运行时融合结果必须附带最强弃权提示。

### 2.5 NHANES 2017–2018：迁移压力测试，不是外部验证（ROUND_47，2026-11-02）

- 数据：NHANES 2017–2018，有标签 n=5,068（PHQ-9≥10，阳性率 0.0906），18–80 岁；未加权。
- 协议：生产 MLP 工件与 cleaner/scaler 原样推理；NHANES 无 `steps`，按生产默认 5000 注入；
  其余缺失按生产默认值填充；另报完整 6 特征子集与 steps=训练均值敏感性。
- 主口径读数：AUC 0.5459 [0.5163, 0.5754]，AUPRC 0.1122，Brier 0.2554；
  平均预测 0.471 vs 实际 0.091；校准斜率 0.2114，ECE 0.3804；分数与 PHQ-9 的 Spearman ρ=0.0484。
- 0.35 阈值：灵敏度 0.747 / 特异度 0.285 / PPV 0.094；0.50 阈值：0.471 / 0.578 / 0.100。
- **不能升级证据等级**：训练标签是 Depresjon 临床分组，NHANES 是 PHQ-9≥10；训练 5/7 特征由
  标签驱动合成，NHANES 特征来源与采集协议不同且无步数。标签、特征、协议同时变化，
  读数既不能归因于模型能力，也不能归因于人群差异，更不能与 0.9451 并列。
- 结论：当前生理模型**没有可用的跨队列迁移证据**；Phase 1 必须先回到真实 actigraphy 特征重做基线。
- 产物：`docs/model-evaluation/NHANES_TRANSPORT_STRESS.md`、
  `backend/scripts/modeling/eval/v1_47/01_nhanes_transport_stress.py`（B=2000，seed=42，可复现）。

### 2.6 真实 actigraphy 分组基线：同队列回顾性，不是外部验证（ROUND_48，2026-11-02）

- 数据：Depresjon 原始 minute-level actigraphy，55 名受试者（23 例 / 32 对照），1,029 个完整日；
  受试者 ID 取自原始逐人文件，TDF 仅作特征定义校验（996 行唯一匹配，33 行键重复但候选一致）。
- 特征：只用真实汇总 `mean_act` / `std_act` / `peak_activity` / `autocorrelation_act`；
  10 特征扩展集仅探索，不构成生产候选。
- 主口径（受试者均值 + LOSO）：AUC **0.6454 [0.4861, 0.7983]**，Brier 0.2232，置换 p=0.024。
- 次口径（日级分组 CV + 受试者聚合）：受试者级 AUC **0.7620 ± 0.0093**（10 次重复），
  合并 OOF 0.7636，置换 p=0.002；日级 AUC 0.6575 ± 0.0057。
- 非分组行级 CV 受试者级 AUC 0.7791，与分组口径差距不大，但仍把同一人当独立样本，
  会低估不确定性，不作为有效口径。
- 敏感性：排除 70 个全零日后 0.7091；仅保留 ≥14 天受试者 0.7010，说明结果部分依赖
  零活动/佩戴天数。多日聚合分数与 MADRS-1/2 的 Spearman ρ≈0.01/0.05，无严重度跟踪证据。
- **证据边界**：同队列、回顾性、n=55；不是外部验证，不升级运行时生理单元
  `synthetic_label_derived` 等级，不能与生产合成特征读数 0.9451 并列，也不支持普通人群、
  消费级可穿戴或临床诊断用途。
- 产物：`docs/model-evaluation/REAL_ACTIGRAPHY_BASELINE.md`、
  `backend/scripts/modeling/eval/v1_48/01_real_actigraphy_baseline.py`（seed=42，B=2000/500）。

### 2.7 真实基线稳健性：规范敏感 + 佩戴混杂（ROUND_49，2026-11-02）

- 规范网格：聚合 mean/median × 自相关缺失 nanmean/zero/drop × 日纳入 all/nonzero/min14，
  共 18 个受试者级 LOSO 规范；AUC **0.5855–0.7364**（中位 0.6569），
  10/18 的 95% CI 下界 >0.5，8/18 覆盖 0.5，仅 1/18 达到 0.70。
  ROUND_48 的 0.6454 只是网格中的一个点，不是稳健性能估计；主口径仍为预注册的
  `mean__nanmean__all`，其余规范只作敏感性，不得事后挑选最大值 0.7364 作为性能。
- 佩戴/记录时长混杂：零活动日比例单变量 AUC 0.3845（对照更高）；仅用
  `zero_day_fraction` / `mean_active_minutes` / `active_days` 的 LOSO 模型 AUC **0.7921**，
  高于 ROUND_48 主口径 0.6454 与多日聚合 0.7620。病例平均 15.6 个完整日、对照 20.9 个，
  `active_days` 与 `min14` 规范同时反映佩戴依从性。
- 影响力检查：排除全零日最多的 control_3/32/31 后，主口径仍在 0.640–0.655，
  佩戴代理模型仍在 0.775–0.792；最好规范从 0.7364 降到 0.7091。
  结论不是单一受试者驱动，但佩戴混杂无法消除。
- **证据边界**：仍为同队列、回顾性、n=55；不是外部验证，不升级运行时生理单元证据等级，
  不能与生产合成特征读数 0.9451 并列。Phase 1 外部队列必须提供佩戴/有效时长，
  并在看标签前预注册聚合、自相关缺失与零活动日处理规则。
- 产物：`docs/model-evaluation/REAL_BASELINE_ROBUSTNESS.md`、
  `backend/scripts/modeling/eval/v1_49/01_real_baseline_robustness.py`（seed=42，B=500）。

### 2.8 多日聚合口径的规范稳健性：0.7620 是网格最大值（ROUND_50，2026-11-02）

- 协议固定：日级 4 特征 logistic regression + 5 折 `StratifiedGroupKFold`（受试者不跨折）
  × 10 次重复（seed 42–51），折外日概率按受试者平均；bootstrap 2,000 次，seed 42。
- 9 规范：自相关缺失处理 zero/mean/drop × 日纳入 all/nonzero/min14。预注册
  `day__zero__all` 精确复现 ROUND_48 的 **0.7620 ± 0.0093**（池化 0.7636，逐位一致，
  差值 <1e-12）；另两个零填充规范也精确复现 0.7091 / 0.7010 敏感性读数。
- 9 规范受试者级 AUC **0.6565–0.7620**（中位 0.7091，极差 0.1055）；8/9 的池化 AUC
  95% CI 下界严格 >0.5，最差规范 `day__mean__min14` 的下界为 0.5000；校准斜率
  3.23–4.28，池化分数明显过度自信。
- 日纳入是主导因子（all 均值 0.7389、nonzero 0.7075、min14 0.6766）；自相关处理均值
  zero 0.7240、mean 0.6936、drop 0.7054。零填充的汇总均值最高，但并非每个档位都最高：
  all/min14 是 zero 最高，nonzero 是 drop 略高（0.7133 vs 0.7091）。这提示
  「未定义自相关填 0」可能携带零活动日信号，不是中性默认值。
- 与 ROUND_49 的 9 对同因子受试者级 LOSO 对照：日级 9/9 更高，差值 +0.0187 到
  +0.0789（中位 +0.0262）。日级训练行更多、目标粒度不同，且 `mean` 与受试者级
  `nanmean` 并非同一估计量；差值不能解释为「多日聚合增益」。
- 结论：0.7620 是预注册规范的精确读数，也是 9 规范网格的最大值；不得单独引用为
  稳健性能估计，也不得事后挑选最大值。仍为同队列、回顾性、n=55，不升级证据等级。
- 产物：`docs/model-evaluation/REAL_BASELINE_PROTOCOL_ROBUSTNESS.md`、
  `backend/scripts/modeling/eval/v1_50/01_protocol_robustness.py`（seed=42，B=2000）。

## 3. 源人群迁移证据（结构化）

| 协议 | n_test | 阳性率 | AUC [95%CI] | Brier | ECE | 校准斜率 | F1 |
|---|---:|---:|---|---:|---:|---:|---:|
| 内部测试（同源） | 4,318 | 0.581 | 0.9134 [0.905, 0.922] | 0.1150 | 0.0163 | 1.028 | 0.8583 |
| Kaggle 同源留出 | 5,574 | 0.585 | 0.9152 [0.908, 0.922] | 0.1131 | 0.0113 | 1.022 | 0.8651 |
| **Kaggle → Mendeley（干净）** | **682** | **0.471** | **0.8633 [0.835, 0.890]** | **0.1734** | **0.1435** | **1.161** | **0.6600** |
| Mendeley → Kaggle（反向压力） | 27,870 | 0.585 | 0.8216 [0.816, 0.826] | 0.1704 | 0.0453 | 0.746 | 0.7888 |

解读边界：跨来源方向同时改变了人群、采集方式和标签定义，不能把退化全部归因于「人群」。
Phase 1 若要做纯人群迁移，必须固定标签定义与特征 schema。

## 5. 运行时映射

运行时由 `backend/app/core/population_scope.py` 提供唯一登记表，API 在
`/api/v1/model/predict/{tabular,text,physiological,fusion}` 的响应中附加
`population_scope`；历史缓存命中时也会重新附加，避免旧缓存缺少披露。

| 运行时模态 | `population_id` | `evidence_level` | `transport_risk` | `automated_decision_allowed` | `abstention_recommended` |
|---|---|---|---|---|---|
| structured | `students_self_report_v1_23` | `internal_source_split` | `degraded` | `false` | `true` |
| text | `chinese_student_text_v1_27` | `groupwise_oof` | `not_evaluated` | `false` | `true` |
| physiological | `depresjon_clinical_v2` | `synthetic_label_derived` | `not_evaluated` | `false` | `true` |
| fusion | `no_aligned_three_modality_cohort` | `not_evaluable` | `unknown` | `false` | `true` |

启发式回退（`fallback_used=true` 或 `model_used` 含 `fallback`）会动态降级为
`heuristic_fallback`，并追加「本次结果未经模型验证」的弃权原因。

## 6. Phase 0 之后仍缺什么

1. **目标人群标签**：当前没有任何一般人群的抑郁标签与现有 12 特征/文本/生理 schema 对齐；
   NHANES 只有 6/7 生理字段（无步数）且标签口径与 Depresjon 不同，只能作压力测试。
   ROUND_48 已在 Depresjon 内用真实 actigraphy 重做受试者分组基线（AUC 0.65–0.76）；
   ROUND_49 进一步显示该读数对规范选择敏感（0.5855–0.7364）且与佩戴/记录时长代理纠缠；
   ROUND_50 又显示多日聚合的 0.7620 是 9 规范网格最大值（0.6565–0.7620），日级与
   受试者级口径不能互相替代。仍无外部成人/临床队列，不能升级生理单元证据等级。
2. **目标域校准样本**：conformal 报告显示，目标域至少 50 条本地标签才能把池化覆盖拉回 0.90；
   分组覆盖需要更多样本。
3. **三模态对齐队列**：现有公开数据无「同一受试者文本 + 可穿戴生理 + 抑郁标签」。
4. **前瞻性验证**：所有现有读数都是回顾性/横断面；没有「预测未来发病/复发」的证据。
5. **公平性**：年龄组差距大、来源差距与标签定义混淆；普通人群的性别/年龄/文化公平性未验证。

在这些缺口关闭前，对外表述必须是「学生/特定临床队列的筛查辅助」，而不是「全人群抑郁预测」。
