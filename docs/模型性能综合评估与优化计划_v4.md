### 4.4 融合引擎

**默认权重**：`structured=0.55, text=0.30, physiological=0.15`

**核心机制**（[fusion_engine.py:142-261](file:///e:/code/bysj/backend/app/ml/fusion_engine.py#L142-L261)）：
1. **基础权重**：0.55/0.30/0.15（结构化/文本/生理）
2. **缺失模态重分配**：`redistribute_weights()` 按剩余模态比例归一化
3. **置信度加权**：`conf_m = 0.5 + 0.5 × |score - 50|/50`（极端分数更确信）
4. **最终权重**：`final_w_m = w_base_m × conf_m`，归一化使 Σ=1
5. **风险等级映射**：`_score_to_level(score)` → 0-4 级

**测试场景覆盖**：
- 单模态：structured / text / physiological 各 1 组
- 双模态：structured+physiological 等
- 三模态：全模态融合（含高/低风险生理数据对照）
- 全部 8 个测试场景 100% 通过

### 5.2 三级回退策略

[model_engine_fallback.py](file:///e:/code/bysj/backend/app/core/model_engine_fallback.py) 实现的回退链：

```
BERT 模型可用？─── 是 ─→ BERT 推理（最佳）
       │
       否
       ↓
TF-IDF + LR 可用？─── 是 ─→ TF-IDF 推理（生产默认）
       │
       否
       ↓
启发式规则（基于关键词字典 + 情感极性）──→ 兜底
```

**结构化回退**：`_structured_heuristic_fallback()` 基于加权规则：
- 风险因子：stress×5 + sleep缺失×2.5 + social低×2.5 + ...
- 保护因子：cgpa×1.5 + age成熟度×0.3
- 校准：健康样本~8分，中风险~54分，高风险~100分

### 5.3 漂移检测机制

[drift_detector.py](file:///e:/code/bysj/backend/app/ml/drift_detector.py) + [model_monitor.py](file:///e:/code/bysj/backend/app/ml/model_monitor.py)：

| 检测项 | 阈值 | 触发动作 |
|--------|------|----------|
| 特征漂移（KS 检验） | p < 0.05 | 记录 + 告警 |
| 预测分布漂移（PSI） | PSI > 0.25 (moderate), > 0.5 (major) | 告警 |
| 性能下降 | 跌幅 > 5% | 告警 + 触发评估 |
| 连续漂移 | ≥ 3 次 | 状态降级 `degraded` |

**监控配置**：
- 漂移检查间隔：60 分钟
- 性能检查间隔：1440 分钟（每日）
- 历史上限：1000 条记录
- 状态：`healthy` / `degraded` / `critical`

4. **回滚记录**：写入 `CanaryRecord` 表，包含版本、时间、原因、指标
